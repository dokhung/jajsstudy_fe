# 이 폴더에 컴포넌트를 만드세요

1. `src/components/MyButton.tsx`를 만드세요.

```tsx
export const MyButton = () => {
  return <button className="bg-blue-500 px-4 py-2 text-white">내 버튼</button>;
};
```

2. `src/router.tsx` 위쪽에 import를 추가하세요.

```tsx
import { MyButton } from "./components/MyButton";
```

3. 같은 파일의 `componentRoutes` 배열에 아래 항목을 추가하세요.

```tsx
{
  title: "MyButton",
  path: "/components/MyButton",
  element: <MyButton />,
},
```

저장하면 첫 페이지에 미리보기와 제목이 표시됩니다.
제목을 클릭하면 등록한 path의 상세 페이지로 이동합니다.
필요한 props는 element에서 직접 전달하세요. 예: `element: <MyButton text="버튼" />`.

`export const MyButton`은 `import { MyButton }`으로,
`export default MyButton`은 `import MyButton`으로 가져옵니다.

개발 서버: `npm run dev` / 화면: http://localhost:3000
